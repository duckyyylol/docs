### 🤖 Custom Commands

<Expandable title="Custom Commands" defaultOpen>
    ### !addcommand
    > *Create a new custom command*
    <Expandable title="Aliases">
        > - `!ac`
        > - `!addcmd`
    </Expandable>
    <br />
    <Expandable title="Arguments" defaultOpen>
        <ResponseField name="trigger" required>
            What a user types in chat to trigger the command
        </ResponseField>
        <ResponseField name="response" required>
            What the bot responds with when a user triggers the command. Supports [variables](#variables)
        </ResponseField>
    </Expandable>
    <br />
    <Frame caption="**Example Usage**: `!addcmd !ping 🏓 Pong!`">
       <img src="/images/coduh/twitch/!addcommand.png" />
    </Frame>

    ### !editcommand
    > *Change the response of a previously created custom command*
    <Expandable title="Aliases">
        > - `!ec`
        > - `!editcmd`
        > - `!changecmd`
    </Expandable>
    <br />
    <Expandable title="Arguments" defaultOpen>
        <ResponseField name="trigger" required>
            The trigger of an existing custom command
        </ResponseField>
        <ResponseField name="new_response" type="OR -level=">
            Replaces the current command's response.
        </ResponseField>
        <ResponseField name="-level=" type="OR new_response">
            `-level=x` sets the required userlevel of the specified custom command

            > - **Broadcaster**: `-level=0`
            > - **Mod**: `-level=2`
            > - **VIP**: `-level=3`
            > - **Viewer**: `-level=4`
        </ResponseField>
    </Expandable>
    <br />
    <Frame caption="**Example Usage**: `!editcmd !ping Ping?`">        
       <img src="/images/coduh/twitch/!editcommand.png" />
    </Frame>
    <br />
    <Frame caption="**Example Usage**: `!editcmd !ping -level=2`">
       <img src="/images/coduh/twitch/!editcommand_level.png" />
    </Frame>

    ### !movecommand
    > *Changes the trigger of a previously created custom command*
    <Expandable title="Aliases">
        > - `!mvcommand`
        > - `!movecmd`
        > - `!swapcmd`
        > - `!swapcommand`
    </Expandable>
    <br />
    <Expandable title="Arguments" defaultOpen>
        <ResponseField name="trigger" required>
            The trigger of an existing custom command
        </ResponseField>
        <ResponseField name="new_trigger" required>
            Replaces the current command's trigger.
        </ResponseField>
    </Expandable>
    <br />
    <Frame caption="**Example Usage**: `!movecommand !ping !ding`">
       <img src="/images/coduh/twitch/!movecommand.png" />
    </Frame>

    ### !deletecommand
    > *Delete a previously created custom command*
    <Expandable title="Aliases">
        > - `!delcmd`
        > - `!removecommand`
        > - `!delcommand`

    <Expandable title="Arguments" defaultOpen>

    </Expandable>
    <br />
    <Frame caption="**Example Usage**: `!delcmd !ding`">
       <img src="/images/coduh/twitch/!deletecommand.png" />
    </Frame>

    <br />
</Expandable>
